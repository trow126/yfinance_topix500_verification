## 3. 仮説

### H1 ファクター投資（価格・配当から作れるファクターのみ）

- **仮説**: 流動性のある銘柄をモメンタム・低ボラ・配当利回りで選んで毎月（または四半期）入れ替える等金額ポートフォリオが、税引後で 1306 を上回る。
- **理由**: 日本株で長期に報告例が多い（ただし日本はモメンタムが弱いことでも知られる）。売買頻度が低く税・コストの不利が小さい。
- **使うデータ**: 終値・出来高・配当（yfinance）。財務ファクター（バリュー・クオリティ）はデータが無いので今回は含めない。
- **特徴量**: `mom_12_1` = 21 営業日前の終値 ÷ 252 営業日前の終値 − 1、`low_vol` = −（直近 252 営業日の日次リターンの標準偏差）、`div_yield` = 直近 252 営業日の配当合計 ÷ 前日終値。合成は各特徴量のパーセンタイル順位の平均。
- **ルール**: 毎月最初の営業日に候補を順位付けし上位 n 銘柄を等金額（口座評価額 ÷ n）で持つ。保有中の銘柄は順位が keep_rank（2n）以内なら持ち続ける。
- **比べる条件（7 条件、うち比較用 1）**:

| ID | 条件 |
|---|---|
| H1-a | モメンタム 12-1、上位 20、毎月 |
| H1-b | 低ボラ、上位 20、毎月 |
| H1-c | 配当利回り、上位 20、毎月 |
| H1-d | 合成（モメ + 低ボラ + 利回り）、上位 20、毎月 |
| H1-e | 合成、上位 20、四半期（1・4・7・10 月） |
| H1-f | 合成、上位 40（keep 80）、毎月 |
| 比較 | モメンタム下位 20、毎月（逆張りが効いていないかの確認） |

- **ランダム比較**: 同じ候補から毎月ランダムに 20 銘柄（seed 0〜19）。
- **予想（結果を見る前）**: 単独ファクターは 3 期間すべてで 1306 を上回らない（確率 70%）。低ボラは 2023-25 の上昇相場で負ける。配当利回りは 2019-22・2023-25 で勝つかもしれないが 2015-18 は不明。合成が 3 期間とも上回り、かつランダム上位 10% に入る確率は 25% と見積もる。

### 3b. H1-g 配当利回り × 減配回避（2026-10-08 に追加登録。H1〜H6 の結果を見た後の追加なので、DSR の N は H1 の 7 条件と合わせて 10 で数える）

- **仮説**: 配当利回り上位 20（H1-c）の候補を「減配していない銘柄」に絞ると、減配前の見かけの高利回り（バリュートラップ）を避けられ、税引後で 1306 を上回る差が安定する。リバランスを減らすと税と売買コストの不利が小さくなる。
- **理由**: clippings の統合（減配リスクは複数年の配当履歴で識別できる、JSAI 2026 高瀬ら。低回転の利点は年 1〜2 回で成立）と、H1-c の結果（3 期間とも上回ったが統計的に弱い）。
- **使うデータ**: 既存の配当履歴のみ。財務データ（黒字継続・自己資本比率）は 2015〜2022 年分が無いので使わない。
- **減配回避の定義**: 選定日の前日時点で、直近 252 営業日の配当合計 ≥ その前の 252 営業日（253〜504 営業日前）の配当合計、かつ前の 252 営業日の配当合計 > 0。前の窓はデータの先頭付近で 200 営業日以上あれば使う（短い分は合計が小さくなり「減配なし」側に倒れる）。
- **データ**: 2019-22・2023-25 の期間では `universe`（2018-01 開始）の前に `universe_2013`（2013-01〜2018-12）を継ぎ足して 2 年分の配当履歴を確保する（重なる 2018 年の終値・配当が一致することを事前に確認。異常値除外もつないだデータで行う）。2015-18 は `universe_2013` のみ（2015-01 の選定時点で前の窓は 2013-01 からの約 238 営業日）。
- **ルール**: H1-c と同じ（候補・順位付け・等金額・keep_rank 40・余りは 1306）。違いは減配回避フィルタとリバランス頻度のみ。
- **比べる条件（3 条件）**:

| ID | 条件 |
|---|---|
| H1-g1 | 配当利回り、減配なし、上位 20、毎月（H1-c との差 = フィルタの効果） |
| H1-g2 | 同、四半期（1・4・7・10 月） |
| H1-g3 | 同、半年（1・7 月） |

- **ランダム比較**: 各条件と同じ候補（減配なし）・同じ頻度・同じ銘柄数でランダムに 20 銘柄（seed 0〜19）。毎月版は毎月引き直す（事前登録の方式と同じ）。
- **合格基準**: 4 章と同じ。4b の DSR は N = 10（H1 の 7 条件 + 今回の 3 条件）で計算し、超過リターンの PSR も併記する。
- **予想（結果を見る前）**: H1-g1 は H1-c と同程度か少し良く、2019-22（2020 年の減配が多い）で差が出る。H1-g3 は税と回転が減るが、利回りの変化に遅れるので 2023-25 で H1-c に劣る。3 期間すべてで 1306 を上回りランダム上位 10% に入る確率は 35%、DSR ≥ 0.95 は 10%、超過リターンの PSR ≥ 0.95 は 15%。
- **実行**: `python scripts/run/run_h1g_dividend_nocut.py --seeds 20` を一度だけ。

### 3c. H8 大量保有報告書（5% ルール）のイベント戦略（2026-10-08 に追加登録。データ取得と同時に登録し、バックテストはこの登録のコミット後に 1 回だけ実行する）

- **仮説**: 活動家的な目的（重要提案行為・経営参加）で提出された大量保有報告書（新規の 5% 超過）の発行者を、提出の翌営業日の終値で買い、60 営業日後に売ると、税引後で 1306 を上回る。
- **理由**: clippings の統合で数値が最も強かった候補（JSAI 2026 鳥海ら: 2021-07〜2026-04、TOPIX 構成、翌営業日寄付買い・60 営業日保有・片道 0.1% で累積 +113.6%、年率 16.7%、Sharpe 0.98。全イベント買いは TOPIX 劣後。自己検証・非査読・件数と DD は不明）。「誰が負けてくれるか」: 活動家の介入後に株主還元・買収が増えることを、公表直後の市場が織り込みきれていない。
- **使うデータ**: EDINET API の大量保有報告書（docTypeCode 350、書類名「大量保有報告書」。変更報告書と特例対象株券等は除く）。API の一覧に出るのは 2021 年 11 月ごろから。`scripts/data/fetch_edinet_large_holdings.py` で提出日・発行者コード・保有目的・保有割合を集める（`data/edinet/large_holdings.tsv`）。株価は既存キャッシュに `universe_2026` をつないだもの。
- **イベントの定義**: 保有目的の文に「重要提案」「経営参加」「経営に参加」「経営への参加」のいずれかを含み、かつ「行わない」「目的としない」「目的ではない」「予定はない」「予定しない」を含まないもの。同じ日の同じ発行者は 1 件と数える。発行者コードが 4 桁の英数字でないもの（投資法人など）は除く。
- **ルール**: 提出日の翌営業日の終値で買う（提出は日中。翌日終値は論文の翌営業日寄付より保守的）。60 営業日後の終値で売る。同時保有 10 銘柄まで、1 銘柄の金額は口座評価額 ÷ 10、余りは 1306。候補は Candidates と同じ（上場 240 営業日以上、異常値除外、1 単元 ≤ 予算）で、売買代金の下限は条件ごとに 1 億円/日または 10 億円/日（活動家の対象は中小型株が多いため 1 億円も試す。1 億円の銘柄に 150 万円を入れると参加率 1.5% で、スリッページは片道 0.3% を適用）。
- **比べる条件（4 条件、うち比較用 1）**:

| ID | 条件 |
|---|---|
| H8-a | 活動家目的、売買代金 1 億円以上、60 営業日保有 |
| H8-b | 活動家目的、売買代金 10 億円以上、60 営業日保有 |
| H8-c | 活動家目的、売買代金 1 億円以上、120 営業日保有 |
| 比較 | 目的を問わない全イベント、1 億円以上、60 営業日（論文では TOPIX 劣後） |

- **ランダム比較**: 各条件と同じイベント日に、同じ候補プールからランダムに同じ数の銘柄を買う（seed 0〜19）。
- **期間**: 2021-12-01〜2023-12-29（前半）と 2024-01-04〜2026-10-08（後半）。3 期間は作れないので、合格基準 3 は「2 期間とも上回る」に読み替える。DSR の N は 4。超過リターンの PSR とブロックブートストラップ（ブロック 20 日）も出す。
- **運用性**: イベントは不定期（週 0〜数件の見込み）。翌営業日の引けに成行で出せるので手動で可。
- **予想（結果を見る前）**: 活動家目的のイベント数は年 50〜150 件、流動性フィルタ後はその半分以下と見込む。H8-a が 2 期間とも 1306 を上回る確率 40%、ランダム上位 10% にも入る確率 30%、DSR ≥ 0.95 は 10%、超過 PSR ≥ 0.95 は 15%。全イベント（比較）は 1306 を下回ると予想（70%）。公表（2026-10-06）直後なので 2026 年分は減衰している可能性がある。
- **実行**: `python scripts/run/run_h8_large_holdings.py --seeds 20` を一度だけ。

### H5 権利落ち後の戻り（3.1 の結果の発展）

- **仮説**: 権利落ち日の終値で配当利回りの高い銘柄を買い、権利落ち前日の終値まで戻ったら売る（窓埋め）方法は、税引後でも 1306 を上回る。
- **理由**: 既存の検証で、権利落ち後に買う方が投資額あたりの効率が良かった。ただし口座全体では 1306 に負けていた（税引前）。
- **使うデータ**: 既存データ（権利落ち日は配当イベントから）。
- **ルール**: 権利落ち日（または 3 営業日後）の終値で、その日に権利落ちした候補を「配当額 ÷ 権利落ち前日終値」の高い順に 1 日 3 銘柄まで買う。同時保有は 15 銘柄まで、1 銘柄の金額は口座評価額 ÷ 15。終値が権利落ち前日の終値以上で売る。max_days 暦日を過ぎたら売る。
- **比べる条件（4 条件）**:

| ID | 条件 |
|---|---|
| H5-a | 落ち日買い、利回り順、1 日 3 銘柄、最大 15、窓埋め / 90 日 |
| H5-b | 同上、180 日 |
| H5-c | 落ち 3 営業日後に買い、90 日 |
| H5-d | 落ち日買い、利回り 2% 以上のみ、90 日 |

- **ランダム比較**: 同じ日の候補からランダムに 3 銘柄（seed 0〜19）、H5-a と同じ出口。
- **予想**: 税引後では 3 期間とも 1306 を上回らない（確率 90%）。株への投資比率が低く（平均 15% 前後）、残りは 1306 なので差は小さい。

### H6 季節性

- **仮説 a**: 年末の節税売りの反動で、年初来リターンが低い銘柄を 12 月末に買って 1 月末に売ると 1306 を上回る。
- **仮説 b**: 月末月初だけ 1306 を持つ（それ以外は現金）方が、持ち続けるより良い（月末月初効果）。
- **理由**: 税制・資金フローによる需給（Turn-of-the-Month 効果、January effect）。
- **使うデータ**: 株価のみ。
- **比べる条件（5 条件、うち比較用 1）**:

| ID | 条件 |
|---|---|
| H6-a | 12 月最終営業日の 3 営業日前に年初来下位 20 を買い、1 月最終営業日に売る。それ以外は 1306 |
| H6-b | 同上、5 営業日前 |
| 比較 | 年初来上位 20（逆） |
| H6-c | 1306 を月末 1 営業日前〜月初 3 営業日目だけ持つ（他は現金） |
| H6-d | 1306 を月末 3 営業日前〜月初 3 営業日目だけ持つ |

- **ランダム比較**: 同じ候補からランダムに 20 銘柄（seed 0〜19）、H6-a と同じ日程。
- **予想**: H6-a/b は 1306 保有とほぼ同じ（1 か月だけ株に入れ替える）ので差は数%以内、税・コスト分だけ負ける（確率 65%）。H6-c/d は保有期間が短く、配当も取りこぼすので 3 期間とも負ける（確率 95%）。

### H7 税の扱い（計算のみ、バックテストしない）

- **問い**: NISA 成長投資枠（年 240 万円、生涯 1,200 万円）に何を入れるか、損出しに意味があるか。
- **方法**: 1 章の 1306 の売却益の税と分配金の税から、NISA に入れた場合の節税額の上限を計算する。戦略が 1306 を税引前で上回っていない限り、NISA に入れるべきは期待リターンの高い方＝1306 になる。損出しは同一年に相殺すべき利益があるときだけ効くので、1306 保有のみでは意味がない。
- **予想**: NISA の節税額は期間あたり最大で売却益の税（2023-25 で約 254 万円の 20.315% 相当部分）に相当し、これは戦略探索で得られる差より大きい可能性が高い。

### 3g. H10 財務フィルタつき高配当（指示書 5 章の候補 1。J-Quants Premium の取得後に実行）
