### 2.3 事後の点検（事前登録にない分析。hypotheses.md 7 章に理由を記録）

1. **1306 に対する超過リターンの統計**（日次の超過リターンから）: H1-c の PSR（超過 SR > 0 の確率）は 0.84 / 0.56 / 0.44、DSR は 0.55 / 0.23 / 0.23。年率の超過リターンは +3.6% / +0.8% / -0.8%（2023-25 は日次の平均では負だが、1306 側が期末にまとめて税を払うため税引後の最終値では上回る）。**「1306 を上回る力」があるとは言えない**。
2. **損失の大きい取引とデータ**: H1-a（モメンタム）の -40〜-87% の取引はすべて保有中に分割の記録がなく、1 日の最大下落も -10〜-35% で、分割未記録ではなく実際の急落（流動性の高い上位 5% のモメンタム銘柄に集中したことによる）。H1-c・H5 の損失上位も同様で、データ異常は見つからなかった。
3. **配当データの照合**: H1-c が 2023-25 に売買した 80 銘柄のうち 77 銘柄について、yfinance の配当合計と J-Quants の年間配当（2024-25 決算期）を比べた。比率の中央値は 1.00、yfinance の方が多い銘柄は最大でも 1.04 倍（分割調整で小さく出る銘柄はある）。**配当の過大記録が利回り順の選定や配当収入を作ってはいない**（2015-22 は J-Quants に無いので未照合）。
4. **売買回数をそろえたランダム比較**（固定乱数: 銘柄ごとに年初に引いた乱数で順位付け、年内は入れ替えない。20 回、売買回数は平均 208 / 218 / 148 回で H1-c と同程度）: H1-c の位置は 1.00 / 0.90 / 0.90 で上位 10% の境界。ランダムの中央値は -46 万 / -183 万 / -209 万円、上位 10% は +101 万 / +140 万 / +199 万円、**最大は +150 万 / +569 万 / +691 万円**。2019-22 と 2023-25 では、流動性のある 20 銘柄を適当に選んで持つだけで H1-c の 3 倍以上 1306 を上回った組み合わせがあり、H1-c の差（+159 万 / +203 万）は「運の良い 20 銘柄」の範囲に収まる。

なし。参考として、基準 4b 以外を満たした H1-c の運用ルールと結果を書く（**推奨ではない**。生存者バイアスと統計的な弱さは 4 章・2.3 節のとおり）。

- 候補: 直近 60 営業日の平均売買代金 10 億円/日以上、上場 240 営業日以上、1 単元 ≤ 口座評価額 ÷ 20
- 毎月最初の営業日に、直近 252 営業日の配当合計 ÷ 前日終値 の高い順に 20 銘柄を等金額（口座評価額 ÷ 20）で持つ。保有中の銘柄は順位 40 以内なら持ち続ける。余りは 1306
- 結果（税引後）: 最終評価額 1,952 万 / 2,133 万 / 2,808 万円（1306: 1,683 万 / 1,974 万 / 2,606 万円）。売買 258 / 250 / 246 回（月 5〜7 回）。納めた税 81 万 / 144 万 / 284 万円。受取配当（税引後）170 万 / 218 万 / 193 万円。最大 DD -27.3% / -33.5% / -18.6%
- 想定される弱点: 高配当株は減配・業績悪化で上場廃止になった銘柄がデータに無い（結果が良く出る側）。2019-22 の DD は 1306 より 4.3 pt 悪い（2020 年 3 月）。1306 保有は売らなければ税を先送りできるが、この戦略は毎月課税される

## 5. H7 税の扱い（計算のみ）

1306 全額保有の税負担と、NISA に入れた場合の節税額の上限（`scripts/run/tax_overlay_h7.py`）。
NISA 枠は 2015-18 / 2019-22 を一般 NISA 480 万円、2023-25 を一般 120 万 + 成長投資枠 480 万 = 600 万円とし、期間初日にまとめて使えたとみなす（上限の見積もり）。

| 期間 | 税引前損益 | 分配金の税 | 売却益の税 | 税合計 | NISA枠 | NISA分の節税（上限） | 税引後損益（NISAなし → あり） |
|---|---|---|---|---|---|---|---|
| 2015-18 | 2,294,491 | 226,995 | 239,131 | 466,126 | 4,800,000 | 149,160 | 1,828,365 → 1,977,525 |
| 2019-22 | 5,951,139 | 299,159 | 909,815 | 1,208,974 | 4,800,000 | 386,872 | 4,742,165 → 5,129,036 |
| 2023-25 | 13,875,926 | 280,291 | 2,538,603 | 2,818,894 | 6,000,000 | 1,127,558 | 11,057,032 → 12,184,590 |

- NISA に入れるべきものは「税引前の期待リターンが高い方」。今回の検証では 1306 を偶然と区別できる形で上回る戦略が無いので、NISA 枠は 1306（または同等のインデックス）に使うのが最も確実な改善で、節税額は期間あたり 15〜113 万円（上限）。
- 損出し（年末に含み損を実現して買い直す）は、同じ年に相殺する利益があるときだけ効く。1306 を持ち続けるだけなら効果は 0。売買を繰り返す戦略では年内の損益通算をエンジンが既に織り込んでいる。
- 実際には期末に売らずに持ち続ければ売却益の税は先送りできる（複利で有利）。この効果は戦略側には無い（売るたびに課税される）ので、1306 保有の優位はこの表より大きい。

## 6. 次に調べる価値があるもの

1. **H1-c の生存者バイアスの補正**: JPX の上場廃止銘柄一覧（2015〜2025）か J-Quants 有料プランで廃止銘柄の株価・配当を補い、同じルールを再実行する。これで 3 期間とも超えたままなら、2026 年以降のデータ（この検証で使っていない期間）で確認する。条件は足さない。
2. **超過リターンで判定する基準に変える**: 次の事前登録では、合格基準 4b を「1306 に対する超過リターンの PSR ≥ 0.95」にする（口座全体の SR は市場の動きに支配される）。
3. **1306 を売らない比較**: 比較対象を「期末に売らない（税を先送り）」にした場合の差も出す。戦略側の不利が大きくなるはず。
4. **H2・H3・H4 のデータ**: 決算発表日（J-Quants 有料 / EDINET XBRL の決算短信）、TOPIX・日経 225 の入替日（JPX 公表）、TDnet の自社株買い・増配。clippings では、決算後ドリフトは第三者の 10 年検証で有意差なし（レオニーの投資研究所、2026-09）。
5. **比較用条件で目立ったもの**（仮説にしていないので結論にしない）: 年末に年初来上位 20 を買う（12〜1 月のモメンタム）が 2015-18 で +314 万、2023-25 で +131 万、2019-22 で -195 万。試すなら事前登録してから。
6. **clippings で数値が最も強い候補（付録 B）**: 大量保有報告書（5% ルール、重要提案行為・経営参加目的に限定）のイベント戦略。EDINET API で 2021-07 以降を再現し、2015〜2020 を自前で埋められるかを先に確認する。週 1 回まとめ買い・同時保有 5 銘柄までなら月数回の手動運用に収まる。
7. **H1-c の改良（事前登録のうえで 1 回だけ）**: 減配回避（複数年減配なし・黒字継続）の属性フィルタを足した年 1〜2 回リバランス版。回転が下がるので税の不利が減り、clippings の指摘（低回転の利点は年 1〜2 回で成立）と整合する。
8. **検証手順の改善**: コスト感度表（片道 0〜0.30%）、約定を翌営業日終値にした版、対 1306 超過リターンのブロックブートストラップ、を次回の事前登録に入れる。
