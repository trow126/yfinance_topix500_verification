# 調査指示書: インデックス（TOPIX）を税引後で上回る個人向け日本株戦略

この文書は、調査を担当するエージェント（または人）への指示書です。
最初に「1. 目的」から「5. 進め方」まで読み、6章の禁止事項を守って作業してください。

---

## 1. 目的

**TOPIX 連動 ETF（1306）を買って持ち続けるだけ**の場合を、
**手数料・税金・資金効率まで含めて**上回る戦略があるかを調べる。

- 見つかった場合: 再現できるコードと検証結果、運用ルールを出す
- 見つからなかった場合: 「何を試して、なぜダメだったか」を出す（これも成果）

「インデックスを上回る」の定義は 4章の基準に従う。見た目の利回りや勝率ではない。

## 2. 前提（運用者）

| 項目 | 内容 |
|---|---|
| 口座 | 楽天証券（国内株の売買手数料0円のゼロコース）、野村證券 |
| 資金 | 約1,500万円。現金はなるべく残さない（遊ばせない） |
| 発注 | 手動。楽天証券は「マーケットスピード II RSS」（Excel）で発注の半自動化が可能 |
| 頻度 | 月数回の売買までなら運用できる。毎日の張り付きは不可 |
| 税 | 特定口座（売却益・配当に 20.315%）。NISA 成長投資枠の利用も考慮してよい |

## 3. これまでに分かっていること（同じ検証を繰り返さない）

このリポジトリで2026年10月に検証した。詳細はコードと `git log` を参照。

### 3.1 月次の権利取り（優待・配当）戦略

権利付き最終日の前日に単元株を買い、-10%刻みでナンピン、取得単価（または窓埋め）で売る。

| 選び方 | 結果 |
|---|---|
| みんかぶ月別優待人気ランキング上位（Wayback の当時版を使用） | ランダムに選んだ場合と差なし。順位に効果なし |
| 2014〜2017年の配当+優待利回りランキング上位 | 同上。下位やランダムに負ける期間もあり |
| 客観指標（売買代金10億円/日以上 × 実績配当利回り順） | 2019〜2025は良いが、2015〜2018では利回りの低い順の方が上。並べ方は安定しない |
| 候補からランダムに選ぶ | 利回り順と同程度。効いているのは「候補の絞り方＋売買ルール」と相場全体 |

- ナンピンは2回より5回が良い（-10%刻みでは5回が実質上限）。最長保有1年は大きな含み損を防ぐ
- 権利落ち**後**に買って窓埋めで売る方が、投資額あたりの効率は良い（配当・優待は捨てる）
- 売る価格を「平均取得単価」から「窓埋め（権利落ち前日終値）」に変えると利益が大きく増えた（ただし上昇相場で保有が長くなった影響を含む）

### 3.2 インデックスとの比較（決定的な結果）

口座1,500万円、待機資金はすべて1306に置いた場合（現金を残さない）:

| 期間 | 1306 を全額保有 | 人気ランキング版 | 客観指標版 |
|---|---|---|---|
| 2019-10〜2022 | +367万 | -52万〜-99万（TOPIX比） | +16万〜+29万 |
| 2023〜2025 | +1,362万 | -188万〜-311万 | -27万〜+8万 |

- しかも**売却益への課税（20.315%）を入れていない**。入れると権利取り側はさらに不利
- 結論: 権利取り戦略は資産を増やす手段としてはインデックス保有を上回らない

### 3.3 検証の落とし穴として実際に起きたこと

- yfinance の配当データに異常値（8303 で1株2億円）。前日終値の20%超の配当は除外している
- yfinance は**上場廃止銘柄のデータがない**（生存者バイアス）。TOB 廃止銘柄は通常プラスなので、方向は戦略によって異なる
- 期間の終わりが急落の底（2018年末など）だと、保有中の含み損で結果が大きく変わる
- 値動きのない日を除いて日次リターンを集計する不具合があった（修正済み）

## 4. 合格基準（すべて満たしたものだけを「インデックス超え」と呼ぶ）

比較対象は **1306 を期間の最初に全額買って持ち続けた場合**（分配金は税引後で現金受取、売却益は期末に一括課税）。

1. **税引後・コスト込み**で1306を上回る
   - 売却益・配当に 20.315% を課税（売るたびに課税。損益通算は同一年内のみ）
   - スリッページ: 売買代金10億円/日以上の銘柄は片道0.1%、それ未満は0.3%以上
   - 手数料は楽天ゼロコースなら0円（2023年10月より前は当時の手数料を入れるか、0円と明記）
2. **現金を遊ばせない前提**で比較する（待機資金は1306で保有、売買時にだけ売買）
3. **複数の独立した期間すべて**で上回る。少なくとも 2015〜2018 / 2019〜2022 / 2023〜2025
4. **偶然でない**: 同じ候補からランダムに選んだ場合（20回以上）の分布の上位10%に入る。
   試した条件の数で割り引いた評価（例: Deflated Sharpe Ratio）も出す
5. **リスク**: 最大ドローダウンが1306より大きく悪化しない（目安 +10ポイント以内）
6. **運用できる**: 2章の前提（手動・月数回）で実行でき、1,500万円を入れても約定に問題がない

## 5. 進め方

### 5.1 手順

1. **仮説を先に書く**: 検証前に `docs/research/hypotheses.md` に、仮説・理由・使うデータ・合格基準・
   比べる条件（最大いくつ試すか）を書いてコミットする。結果を見てから条件を足さない。
   足した場合は理由と日付を記録する
2. **データの確認**: 期間・銘柄数・欠損・生存者バイアスの向きを先に確認して書く
3. **実装**: 既存のエンジン（下記）を拡張するか、新しいモジュールを作る。テストを書く
4. **検証**: 4章の基準で評価。前半で条件を選び、後半は確認だけに使う（後半を見て条件を変えない）
5. **報告**: 7章の形式で出す

### 5.2 調べる候補（優先度順。根拠のある仮説から）

| # | 仮説 | 根拠・狙い | 必要なデータ |
|---|---|---|---|
| 1 | **ファクター投資**（バリュー・クオリティ・低ボラ・モメンタムの組み合わせ） | 日本株で長期に報告例が多い。売買頻度が低く税・コストの不利が小さい | 株価・財務（EDINET 有報、J-Quants） |
| 2 | **決算発表後の株価ドリフト**（好決算後に買う） | 情報の織り込みの遅れ。小型株ほど大きいとされる | 決算短信の発表日・内容（J-Quants は無料版が直近2年のみ） |
| 3 | **指数の銘柄入れ替えイベント**（TOPIX 組入・日経225 採用） | 指数連動資金の売買による一時的な歪み | 入れ替えの発表日・実施日（JPX 公表資料） |
| 4 | **自社株買い・増配の発表後** | 株主還元の発表後の上昇が続くか | TDnet 適時開示（過去分の入手方法を要調査） |
| 5 | **権利落ち後の戻り**（3.1 の結果を発展） | 落ち後に買う方が効率が良かった。対象を絞れば超えるか | 既存データで可 |
| 6 | **季節性**（年末の節税売り → 1月の戻り、月末月初） | 税制・資金フローによる需給 | 株価のみで可 |
| 7 | **税の扱いで差をつける**（NISA に何を入れるか、損出し） | 戦略ではなく税引後リターンの改善。インデックスとの組み合わせで効く可能性 | 不要（計算のみ） |

レバレッジ（信用取引・レバレッジETF）でリターンを上げるだけのものは「インデックス超え」とみなさない。
比べるならリスクをそろえて（同じ最大ドローダウンや同じボラティリティで）比べる。

## 6. 禁止事項・注意

- **結果を見てから条件を足し続けない**（過去データへの合わせ込み）。試した条件はすべて記録する
- 後半（確認用）の期間を見て条件を変えない
- 未来の情報を使わない（選定日より後に分かるデータ・後から修正された財務値を使わない）
- 上場廃止銘柄が欠けていることの影響を必ず書く。可能なら J-Quants 等で補う
- `.env` のキーの値を表示・ログ出力・コミットしない
- 実際の発注や証券口座の操作はしない（バックテストのみ）
- 個別銘柄の推奨はしない。出すのはルールと検証結果

## 7. 報告の形式

`docs/research/report_<日付>.md` に次を書く。

1. 結論（1〜3行）: インデックスを超える戦略が見つかったか
2. 試した仮説の一覧と、それぞれの合否（4章の基準ごと）
3. 合格した戦略があれば: 運用ルール（2章の前提で実行できる形）、期間ごとの結果表（1306比・税引後）、
   ランダム比較の分布、最大ドローダウン、必要資金、想定される弱点
4. データの制約（生存者バイアス、欠損、期間）と、それが結論に与える影響の向き
5. 次に調べる価値があるもの

数値は「税引前／税引後」「優待・配当の見積もりを含むか」を必ず明記する。
